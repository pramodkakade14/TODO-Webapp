# TODO-Webapp

**Description:-**
To-Do List Web App is a lightweight, responsive task management tool built with pure HTML, CSS, and JavaScript.
This project allows users to quickly add, manage, and track their tasks without needing a backend or database. It is designed with a clean, modern user interface and focuses on core functionality and ease of use.

**Features:-**
Add Tasks: Easily input new tasks to your list.
Delete Tasks: Remove completed or unwanted tasks.
Responsive Design: Works smoothly on mobile and desktop browsers.

**Technologies Used:-**
HTML5 for structure
CSS3 for styling (Flexbox/Grid)
JavaScript (Vanilla) for logic and DOM manipulation
